# Contributing

## Before Opening an Issue

- Check the README and `docs/` first.
- Include board revision, schematic revision, operating system, cable, baud rate, and wiring.
- Attach logs, oscilloscope captures, or clear photos where useful.
- Never publish private customer data or credentials.

## Design Changes

- Update the Eagle schematic and board together.
- Run an electrical rule check and design rule check.
- Export updated PDF, Gerbers, and mechanical files when applicable.
- Update the README or relevant document when behavior changes.
- Record unverified assumptions in `docs/VALIDATION.md`.
